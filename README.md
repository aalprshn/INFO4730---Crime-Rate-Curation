# INFO 4730 – Crime Rate Curation Project

This repository was created for INFO 4730 (Digital Curation and Preservation) to preserve and organize historical crime data from 1975 to 2015.  
The dataset contains yearly crime statistics for multiple U.S. jurisdictions, including population, violent crime counts, homicides, assaults, robberies, and per-capita measures.

---

## Repository Structure

The dataset is divided into four curated time periods:

- **1975–1985** – Early historical crime data  
- **1986–1995** – Late 80s and early 90s crime trends  
- **1996–2005** – Transition decade with updated reporting  
- **2006–2015** – Most recent years included in the dataset  

Each folder contains one CSV file per year.

This structure supports easier access, comparison, and long-term preservation by grouping files into meaningful ranges.

---

## Purpose of the Project

The purpose of this repository is to:

- Preserve crime data in a consistent and organized structure  
- Support digital curation practices taught in INFO 4730  
- Provide long-term access to historical crime information  
- Enable users to explore changes in crime rates across four decades
